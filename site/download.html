Installing

Three steps, about two minutes.

1
Unzip and move

Mac: double-click the zip, then drag ForgeAI.app into Applications. Windows: unzip, then run Install ForgeAI 2.28.0 (x64).exe.

2
Open it once and let it through

Your computer will warn that ForgeAI is from an unidentified developer — the note below has the two clicks that handle it. On Windows, say yes when it asks to allow ForgeAI through the firewall, or other computers cannot reach it.

3
Get a model

Setup asks which AI should answer. Choose the free local one — about 2 GB, downloaded once, works offline forever — or paste a Claude or OpenAI key. You can add more later under Models.

“Unidentified developer” / “Windows protected your PC”ForgeAI is not yet signed with an Apple or Microsoft certificate, so both systems warn you the first time. Mac: right-click ForgeAI → Open → Open, or System Settings → Privacy & Security → Open Anyway. Windows: “More info” → “Run anyway”. New in 2.28.0

What changed.

The short version of what is different since the last release.

A model picker that tells you the truth

Hover any model and a card rises beside it with four bars — capability, speed, context and cost. The figures are measured on your own computer, not quoted from someone else's benchmark. A model nobody has used says so instead of showing a number.

It already knew how good your models were

ForgeAI quietly asks every local model six short questions — follow an instruction, hold a format, do arithmetic, admit ignorance, write JSON, write working code. That score now drives the capability bar. Cloud models show an empty bar, because testing them would cost you money.

Real provider logos

Anthropic, OpenAI, Qwen, Gemini and DeepSeek, from their own artwork. Anything else wears the ForgeAI mark. The marks drawn in a single dark colour flip in dark mode so they do not disappear.

Reasoning, per model

Low, Medium or High, remembered for each model separately, and it overrides the conversation setting when you set it. It is not a label — it changes the instructions the model is given.

Thirty-two role icons

Bookkeeping, support, logistics, legal, scheduling. A team of twelve reads at a glance instead of twelve coloured squares, and each agent gets the right icon automatically from its job title.

Settings that stopped shouting

Of 340 settings, 178 carried a sentence of explanation that was on screen every single time. Now one quiet line that opens when you want it, or off entirely once you know your way around.

Requirements

What you need.

ForgeAI itself is small. Local models are what use memory — setup picks one that fits the computer it is on.

Mac

macOS 13 or later. 8 GB of memory runs the built-in assistant; 16 GB or more runs larger models comfortably.

Windows

Windows 10 or 11, 64-bit. 8 GB minimum. An NVIDIA card is used automatically and makes local models much faster.

Linux server

Any 64-bit distribution with Node 22. Runs headless; you use it from a browser anywhere on your network.

Disk

About 600 MB for ForgeAI, plus 2–8 GB for each local model you download. You set the ceiling in Settings.

ForgeAI

Private AI that runs on computers you own. Made in Hawke's Bay, New Zealand.
