Forge AI

Open-weight AI models, running on your own computer. Download a model once and chat offline — no account, no subscription, nothing sent to a server.

macOS

Apple Silicon (M1 or later) · runs on the GPU via Metal

Download for Mac All versions
  1. Open the .dmg and drag Forge AI to Applications.
  2. First launch: right-click the app and choose Open, then Open again.
  3. Go to Models, download one, and start chatting.

Windows

64-bit Windows 10 or 11 · runs on the processor

Download for Windows Portable version
  1. Run the installer. If SmartScreen appears: More info, then Run anyway.
  2. Launch Forge AI from the Start menu.
  3. Go to Models, download one, and start chatting.

Why the security warnings

Forge AI is not code-signed. Signing certificates cost money each year, and this is a free project. Both operating systems therefore warn you the first time you open it. The steps above are the normal way past that warning. If you would rather check for yourself, the whole source is in this repository and the installers are built from it by GitHub, not uploaded by hand.

What you need

About 1 GB of disk for the app, plus the model you choose — the smallest useful one is around 1 GB and the better ones are 4 to 9 GB. 8 GB of memory runs small models comfortably; 16 GB and up opens the larger ones. Forge AI reads your hardware and labels every model Recommended, Compatible, May be slow or Not enough memory before you download it.
