Your AI. Your hardware.
Your control.

A desktop AI app that downloads models and runs them on your own machine. No account, no API key, no data leaving your computer.

macOS Your system
macOS 12 Monterey or later · Apple Silicon or Intel
Apple Silicon (M1–M4) Intel Mac

Unsigned build: on first open, right-click the app and choose Open, then confirm. One time only.

Windows Your system
Windows 10 or 11 · 64-bit
Installer (.exe) MSI package

Unsigned build: Windows may show “unrecognised app”. Choose More info → Run anyway. One time only.

Nothing else to install
No Python, Node, Docker, Ollama or terminal. The inference engine is inside the installer.
Models
Browse, download and delete from inside the app. Every file is checksum-verified before it loads.
Private by construction
The engine binds to localhost only. There is no server to talk to.

Installing

Four steps, about five minutes, most of which is the model download.

  1. Download the file for your system above.
  2. macOS: open the .dmg, drag Forge AI to Applications, then right-click it and choose Open.
    Windows: run the .exe and follow the installer.
  3. Open Forge AI. It reads your hardware and tells you what it found. Nothing is sent anywhere.
  4. Go to Models, download Qwen2.5 1.5B (about 1.1 GB — the fastest way to a first answer), press Load, and start chatting.
