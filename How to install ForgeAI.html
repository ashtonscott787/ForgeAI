Overview

One app, nothing else to install

ForgeAI is a complete AI platform in a single application. It includes its own model engine, so there's no Ollama, LM Studio, Python or anything else to set up. Install it, sign in, and you can chat, run agents, make documents and artifacts, and download and run open models — entirely on hardware you control.

One ForgeAI is the hub. Other computers join it to share their spare power. Together they act like one larger computer: when a machine is idle, or has capacity to spare while someone uses it, ForgeAI can run work there. People you give permission to can use that pooled power too, and everything can be seen and managed from the hub — including computers in another office or on another network.

Private by default

Models and data stay on your computers. Cloud providers are optional, and routing rules can forbid data ever leaving your network.

One pool of power

CPU, GPU and memory across every joined computer, shown as one total, with what's free to use right now.

Works everywhere

Computers on different networks or VLANs join over an encrypted link — no VPN required, though you can use one.

Managed from one place

Load, download and delete models on any computer, restart it, share it or remove it — all from the hub.

ForgeAI is business software your administrators can see. However it runs, it stays listed in Services and in the computer's apps list so IT can always find and remove it. It isn't designed to hide from the people who own or manage the machine.

Install

Set up the hub, then add computers

1 · The hub

On the computer that will coordinate everything, open the installer and follow it. On a Mac that's ForgeAI.app; on Windows, Install ForgeAI (x64).exe. The first account you create is the owner — you. Then open Computers → Network settings and turn on Be the hub.

2 · Everything else

On the hub, go to Computers → Add a computer. Pick the system and whether it runs as a normal app or in the background, and copy the one line it gives you. Run that line on the other computer and it installs, joins the hub, and appears on the map — no sign-in needed on the far end.

💡
The command carries a join string that lists every address the hub can be reached on. The new computer tries each until one connects, so a machine on another VLAN or off-site joins by itself. For off-site computers, set a Public address under Network settings first.

Silent & remote

Deploy with your own tools

For Intune, Jamf, NinjaOne, PDQ, Ansible or a script. Replace HOST:PORT and the key with the values from Computers → Add a computer (or the raw join string).

Windows

Normal, for everyone, starts at login · run as admin / SYSTEM
"Install ForgeAI (x64).exe" /S /ALLUSERS /HUB=HOST:PORT /KEY=FGE-XXXXX /PRIORITY=low /START
Background service · one per machine, starts at boot
"Install ForgeAI (x64).exe" /S /SERVICE /JOIN=FGJ1....

Via a deployment tool, wrap it so the tool waits and /S is passed cleanly:

PowerShell (NinjaOne, PDQ…)
Start-Process -FilePath "C:\Windows\Temp\Install ForgeAI (x64).exe" `
  -ArgumentList '/S','/ALLUSERS','/HUB=HOST:PORT','/KEY=FGE-XXXXX','/PRIORITY=low','/START' -Wait
⚠️
Run it as administrator or SYSTEM and always include /ALLUSERS (or /SERVICE). Without it, a run-as-SYSTEM install lands in the hidden SYSTEM profile and never starts. Switches: /PRIORITY=low|lowest|normal /NOYIELD /LEND=idle|always|never /HIDEICON /AUTOSTART /NAME="Office PC 3" /D=C:\path.

macOS

Normal app, starts hidden at login
sh install-unix.sh --silent --autostart --hub HOST:PORT --key FGE-XXXXX
Background service (needs sudo)
sudo sh install-unix.sh --silent --service --hub HOST:PORT --key FGE-XXXXX

Linux (incl. Raspberry Pi)

Server edition as a system service
sudo sh install-unix.sh --silent --hub HOST:PORT --key FGE-XXXXX

Straight from the hub

If the hub's remote link is on, a single line downloads and installs in one step (the join string is built in):

Mac / Linux
curl -fsSk 'https://HOST:PORT/node/deploy/install.sh?key=FGE-XXXXX' | sudo sh -s -- --silent

The join string

Where it comes from, what's in it

You never write it by hand. On the hub, Computers → Add a computer (or Network settings → Remote link → New enrolment key) creates it and bakes it into every command. It begins with FGJ1. and contains, all signed:

  • every address the hub answers on — each network interface and VLAN, your public address, and the relay;
  • the enrolment key (limited to a number of computers and days, and revocable);
  • the hub's certificate fingerprint, so the connection can't be impersonated.

A new computer tries each address until one works. That's what lets different-VLAN and off-site machines join with nothing done on the far end.

Uninstall

Remove it cleanly, anywhere

From the hub, open a computer and choose Uninstall — it removes ForgeAI there and takes away its access at the same time. Or run the uninstaller directly:

Windows · add /PURGE to delete data too
"Uninstall ForgeAI.exe" /S
Mac / Linux · --purge to delete data, --dry-run to preview
sudo sh uninstall-unix.sh --silent

The uninstaller removes every ForgeAI install on the machine — per-user, all-users, the service, shortcuts, start-up and firewall entries. Your data is kept unless you ask for it to be deleted. On a Mac you can also double-click Uninstall ForgeAI.command.
